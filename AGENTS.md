# Contributor automation

Public identity: **SCUM-SENF — SCUM Server Event & Notification Framework**.

This repository is still in foundation/FuE preparation. Do not invent architecture, supported integrations, performance claims, or production readiness.

Rules for agents and automated contributors:

- Keep public text concise and evidence-backed.
- Do not add frameworks, cloud services, LLMs, databases, or dependencies without a scoped need.
- Do not copy private chat, Notion, roadmap, threat-model, or internal rationale into this public repository.
- Never commit secrets, tokens, credentials, private server data, player data, or logs containing personal information.
- Prefer primary sources for SCUM/server behavior that may change over time.
- Add tests and verification with implementation changes once code exists.
- Material AI-assisted contributions must be reviewed by a human before merge.

Bots may propose. Humans approve.
